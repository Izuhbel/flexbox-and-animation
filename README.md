# CSS Flexbox and Animation

A CSS project focused on practising layout techniques and animations.

## Overview

This project explores how CSS can be used to position elements, create layouts and add movement to webpage components.

## Concepts Practised

- CSS Flexbox
- Element positioning
- CSS transforms
- Keyframe animations
- Animation timing and repetition
- Responsive styling

## Built With

- HTML5
- CSS3

## Getting Started

Open `index.html` in your web browser to view the project.
